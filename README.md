# data_vis_port_projects
WYSblue-dev
WYSblue-dev is a Python project focused on generating, parsing, and visualizing pay data. The project includes utilities for data parsing, pay generation, and creating visualizations using both Matplotlib (pyplot) and Plotly.
Features
	•	Pay Generator: Easily generate and refine pay data for analysis.
	•	Data Parsing: Import and process pay data for visualization.
	•	Visualization: Create plots and graphs using both Matplotlib and Plotly.
	•	Modular Structure: Organized codebase for easy maintenance and extension.
